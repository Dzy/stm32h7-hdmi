# 2026-09-06 baseline cleanup

This tree is based on the user-supplied Codex `tnc155-emulator-fixed-rom5`
version, not on the older FD-duplex branch.

Locked points preserved:

- MAIN mapper: P3 direct `>0000..>0FFF`, mapped `>1000..>DFFF`, standard direct `>E000..>FFFF`.
- User RAM: contiguous 72 KiB at physical `>EE000..>FFFFF`.
- Mapper page `>FD` is ordinary User RAM; no FD TX/RX device or checksum hooks.
- Missing/invalid User RAM image starts as zero; bundled image is exactly 73728 zero bytes.
- New verified P5 `2340005E` is bundled under `rom-overrides/` and has SHA-256
  `fed805fdecfeb9ae2f9b9533e0cb5840c1dd2ccbc0c3ebedc0dadd405ef87523`.
- SDL keyboard injects P8279 raw matrix codes, not P3 logical codes.

Keyboard regression protection:

- raw CE `>7F` -> P3 logical `>69`
- raw ENT `>65` -> logical `>65`
- raw 0 `>75`, 1 `>74`, 2 `>70`, 3 `>6B`, 4 `>73`, 5 `>6F`,
  6 `>6A`, 7 `>68`, 8 `>6E`, 9 `>69`
- raw X/Y/Z/IV `>77/>7C/>7D/>7E`
- P raw `>43`; I-mode raw `>44` is defined and ROM-tested. The Codex SDL
  behavior `I` -> IV is intentionally preserved; no guessed host binding was
  added for the separate I-mode key.

Additional cleanup:

- P5 override path is package-local and `TNC155_ROM_DIR` is now a real CMake
  cache variable, so `-DTNC155_ROM_DIR=...` works.
- SDL2 is optional for headless/unit-test builds; with SDL2 installed the
  normal `tnc155` graphical target is built as before.
- `tnc155-headless` is built independently of SDL2.
- stale `MEMORY_EVIDENCE.md` wording that still described FD as duplex was corrected.
- CLP watchdog power-on state and 3 MHz internal-cycle timing were aligned with
  the current emergency-stop handoff model (23 ms CLP, 76 ms MAIN).
- ROM regression test now validates the P3 raw-key translation table.

Verification in the build environment: 12/12 CTest tests pass and a
1,000,000 combined-instruction headless run completes without unmapped accesses.
